The Surround · 1 model, 8 layers, 4 scenarios

Same model.
Watch the answer change.

One deliberately mediocre model answers every turn. The eight layers around it — retrieval, tools, memory, guardrails, and four more — decide whether the reply is grounded, safe, and measurable. Toggle them and the verdict flips.

Educational model. The "model" is a canned, deterministic function — no network, no API keys. Every run is reproducible; the point is what the layers do to it.
